# Учёный Кот-Шахматист — исходники

Обычный статический сайт без сборки: открыть `index.html` в браузере (или выложить папку на любой хостинг).
Файлы подключаются в `index.html` (список FILES, порядок важен) — новый файл добавлять туда же.
После любых правок в src/ поднять VERSION в `index.html`, иначе браузер может показать старую версию из кеша.
Страница сама проверяет VERSION на сервере (при открытии и при возврате во вкладку) и перезагружается, если вышла новая — кроме момента, когда ребёнок решает задачу.

src/
  config.js                  настройки: попытки, очки за задачу, цель урока, рейтинг Эло
  data/puzzles.js            VOLUMES — книги на полке, у каждой свой Lichess CSV
  core/chess.js              правила шахмат: FEN, легальные ходы, мат (без DOM)
  core/puzzle-source.js      задачи → тома; pickNext — выбор следующей задачи (место для будущего алгоритма)
  ui/texts.js                все тексты: реплики Кота, названия приёмов, описания ходов
  ui/visuals.js              визуальные элементы: SVG фигур и Кота, иконки, звук, конфетти, модалки
  ui/board.js                BoardController — отрисовка доски, анимация, подсветки, drag-and-drop/тапы
  game/puzzle-controller.js  PuzzleController — решение одной задачи: проверка ходов, попытки, подсказки, ходы по стрелкам
  game/progress.js           игроки (по id), рейтинг, очки, уроки, сохранение (localStorage + облако артефакта)
  app/screens.js             экраны и навигация: полка, том, урок, итоги урока, игроки
  app/main.js                точка входа
  styles.css

Правила (числа — в config.js):
  Урок = набрать 40 очков. «Решать» на главной берёт задачи вперемешку из всех книг, кнопка
  на странице книги — только из неё. Внутри: сначала новые, потом нерешённые чисто.
  Реплики Кота: похвала — по случайной метке задачи (TAG_PRAISE), советы после ошибок — по теме книги (BOOK_TIPS), ui/texts.js.
  Очки за задачу: 2 — без ошибок, 1 — с 1–2 ошибками (подсказка = ошибка), 0 — после 3-й ошибки
  (включаются зелёные стрелки, ребёнок сам доигрывает решение по ним).
  Рейтинг: старт 100, Эло с K=20 против рейтинга задачи Lichess. Чистое решение — победа,
  всё остальное — поражение (±10 против задачи равного рейтинга).
