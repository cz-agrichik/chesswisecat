# Учёный Кот-Шахматист (The Wise Chess Cat) — исходники

Обычный статический сайт без сборки: открыть `index.html` в браузере (или выложить папку на любой хостинг).
Скрипты подключаются в `index.html` (список FILES, порядок важен) — новый файл добавлять туда же.
После любых правок в src/ поднять VERSION в `index.html`, иначе браузер может показать старую версию из кеша.
Страница сама проверяет VERSION на сервере (при открытии и при возврате во вкладку) и перезагружается,
если вышла новая — кроме момента, когда ребёнок решает задачу.

## Команды

Нужен Node.js. Один раз: `npm install`, потом `npx playwright install chromium`.

- `npm test` — все тесты; `node tests/run.js lesson` — только те, в имени которых есть «lesson».
- `npm run build` — собрать `dist/chesswisecat.html` для публикации.
- `npm run stats` — сводка по всем книгам; `npm run stats -- fork 20` — книга fork и 20 примеров.

## Как добавить книгу

1. Положить задачи в `src/data/books/<id>.js`: `PUZZLE_CSV['<id>'] = \`…CSV…\`;`
2. Добавить строку `{ id: '<id>', color: '#…' }` в `src/data/books.js` на нужное место полки.
3. Добавить название книги в `books` каждого файла `src/i18n/*.js`: `'<id>': 'Название'` или
   `['Название', 'Короче для корешка']`.
4. `npm test` проверит, что у книги есть файл и названия на всех языках, а все задачи корректны.

## Как добавить язык

Скопировать `src/i18n/en.js` в `src/i18n/<код>.js`, перевести, поменять код, название и флаг в
`Texts.add(...)`, добавить файл в FILES в `index.html`. Тест сверит, что ключи те же, что в английском.

## Правила (числа — в config.js)

- Выбор задачи взвешен по рейтингу (CONFIG.ratingWindow): цель — от x−200 до x+100 (x — рейтинг
  ребёнка), на 150 дальше — вдвое реже, на 300 — вчетверо, дальше — не выпадает.
- Урок = набрать 40 очков. «Решать» на главной берёт задачи вперемешку из всех книг, кнопка на
  странице книги — только из неё. Внутри: сначала новые, потом нерешённые чисто.
- Очки за задачу: 2 — без ошибок, 1 — с 1–2 ошибками (подсказка = ошибка), 0 — после 3-й ошибки
  (включаются зелёные стрелки, ребёнок сам доигрывает решение по ним).
- После ошибки — пауза «подумай»: доска сереет, песочные часы, k-я ошибка → k × N секунд
  (N — настройка игрока, по умолчанию 3). После последней ошибки — сразу стрелки.
- Рейтинг: старт 100, Эло с K=20 против рейтинга задачи Lichess. Чистое решение — победа,
  всё остальное — поражение (±10 против задачи равного рейтинга).
- Реплики Кота — только похвала / подбадривание. О самой задаче не говорится ничего (ни темы,
  ни «мата») — всегда «найди лучший ход».
- Настройки игрока (✏️): имя, аватар, язык (английский по умолчанию), пол (мальчик / девочка /
  не важно — при «не важно» только нейтральные фразы), пауза после ошибки.
- Шрифты: Andika / Didact Gothic (сделаны для детей, которые учатся читать; есть кириллица и
  греческий), заголовки — Rubik Bubbles.
- История: у игрока хранятся последние 400 задач (время, книга, рейтинг задачи, результат,
  изменение рейтинга); кнопка 📈 рядом с игроком вверху.
- Удаление игрока: ✏️ → «Удалить игрока» → нужно вписать его имя. В облаке вместо записи остаётся
  метка { deleted: true }, чтобы другие устройства тоже убрали игрока, а не загрузили его обратно.
