# Шахматята — исходники

Обычный статический сайт без сборки: открыть `index.html` в браузере (или выложить папку на любой хостинг).
Скрипты подключаются в `index.html` по порядку — новый файл добавлять туда же.

src/
  config.js                  настройки (размер пакета, попытки, очки, уровни)
  data/puzzles.js            задачи в формате Lichess CSV (+ PACKS_OVERRIDE для ручных пакетов)
  core/chess.js              правила шахмат: FEN, легальные ходы, мат (без DOM)
  core/puzzle-source.js      задачи → пакеты; место для будущего алгоритма подбора
  ui/texts.js                все тексты: реплики Котика, названия приёмов, описания ходов
  ui/visuals.js              визуальные элементы: SVG фигур и Котика, иконки, звук, конфетти, модалки
  ui/board.js                BoardController — отрисовка доски, анимация, подсветки, drag-and-drop/тапы
  game/puzzle-controller.js  PuzzleController — решение одной задачи: проверка ходов, попытки, подсказки, показ ответа
  game/progress.js           игроки, очки, звёзды, бесконечные уровни, сохранение (localStorage + облако артефакта)
  app/screens.js             экраны и навигация: полка, пакет, решение, итоги, игроки, лидеры
  app/main.js                точка входа
  styles.css
